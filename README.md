# 📈 指對數觀念教練（數A 第5–7章）

高中數學 A 版本「第5章 指數函數、第6章 對數與對數律、第7章 對數函數」的互動練習網頁。
重點是**找出觀念哪裡不對**，並用輕鬆、鼓勵的方式指正；月考前也能用「月考衝刺」練習在短時間內答對。

## 功能

| 功能 | 說明 |
|---|---|
| 四層次＋考題型 | 每章分「基本觀念 → 基本應用 → 綜合應用 → 進階應用」，再加上仿學測／分科測驗的題型，共 56 題 |
| 錯誤觀念診斷 | 每個錯誤選項都對應一個常見的錯誤觀念（例如「底數小於 1 時忘記變號」「首數與位數」），選錯時立刻說明錯在哪裡，並讓學生再試一次 |
| 引導提示 | 每題 2–3 則提示，一次只給一步，引導學生自己想出答案 |
| 快速解題技巧 | 每題答完都會顯示「⚡ 快速解題」的方法 |
| 月考衝刺 | 隨機出題、計時作答，在建議時間內答對有加分；會優先出沒做過或上次答錯的題目 |
| 觀念診斷報告 | 彙整學生累計最常犯的錯誤觀念，可一鍵「針對這個觀念練習」 |
| 圖形實驗室 | 用滑桿改變底數 a，觀察 y=aˣ 與 y=logₐx 的單調性、必過點與對稱性 |

鍵盤操作：`1`–`4` 作答、`H` 看提示。練習紀錄存在瀏覽器（localStorage），不會上傳。

## 使用方式

- **線上使用**：開啟 GitHub Pages 網址即可（手機、平板、電腦都可以）。
- **離線使用**：下載整個資料夾，直接用瀏覽器打開 `index.html`。不需要安裝任何套件。

## 新增或修改題目

所有題目都在 `js/questions.js`。每題格式如下：

```js
{
  id: '6-20', ch: 6, lv: 5, src: '113學測', sec: 40,
  q: '已知 log 2≈0.3010，則 2^{50} 是幾位數？',
  hints: ['先算 log 2^{50}。', '位數 = 首數 + 1。'],
  opts: [
    { t: '16 位數', ok: 1 },
    { t: '15 位數', m: 'DIGITS', fb: '首數 15 代表 16 位數喔！' },
  ],
  sol: 'log 2^{50}=15.05，首數 15，是 16 位數。',
  tip: '位數 = 首數 + 1。',
},
```

- `lv`：1 基本觀念、2 基本應用、3 綜合應用、4 進階應用、5 歷屆考題型
- `m`：錯誤觀念代碼，對照 `MISCONCEPTIONS`（也可以自己新增）
- 排版語法：`2^{x}` 上標、`log_{2}x` 下標、`#f{1}{8}` 分數、`#r{2}` 根號

> 目前「歷屆考題型」為依學測、分科測驗常見題型改編的題目。若要放入大考中心的原題，照上面格式加入並在 `src` 註明年度即可。
